# Platforms

One account, three ways in. Settings, wallets, snipers, copies and history are shared, so you can start a trade on your phone and manage it in the browser.

| | Browser | Telegram | Android |
|---|---|---|---|
| Full app (every tab) | ✓ | ✓ (opens the app inside Telegram) | ✓ |
| Trade, snipe, copy, whale copy | ✓ | ✓ | ✓ |
| Alerts | In-app | Telegram messages | Push notifications |
| Home-screen widgets and floating overlay | | | ✓ |
| Updates | Instant | Instant | Instant for features; the app shell updates rarely |

## Browser

Open [augur-trade.com/app](https://augur-trade.com/app/). It works on desktop and mobile browsers.

## Telegram

Use **Start in Telegram** on [augur-trade.com](https://augur-trade.com). The bot sends trade alerts and confirmations, and opens the full app in one tap. Your Telegram account is also how you sign in everywhere else.

## Android

The Android app loads the same live web app, so features ship to it the moment they ship to the browser. On top of that it adds:
- **Push notifications** for sells, buys, snipes, launches, whale copies and chat (pick which in **More → Settings**)
- **Widgets:** P&L, positions and whale-copy stats on your home screen, or as a floating overlay above other apps
- an **update button** that appears when a new app shell is available

## Demo mode

Add `?explore=1` to the app address, or use the [live demo link](https://augur-trade.com/app/?explore=1). Everything is clickable, data is live, and nothing touches real money.
